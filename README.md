# Аренда биотуалетов в Красноярске

Сайт на Flask, оптимизированный для работы с **Cursor Agent**.

## Быстрый старт в Cursor

1. Откройте эту папку в Cursor
2. В терминале выполните:

```bash
pip install -r requirements.txt
python app.py
```

3. Откройте в браузере: http://127.0.0.1:5000

## Что умеет сайт

- Адаптивный дизайн
- Карточки с ценами
- Форма заявки
- Сообщения об успешной отправке
- Заявки выводятся в консоль

## Работа с Cursor Agent

В проекте есть файл `.cursorrules` — агент знает стек и правила.

Примеры команд агенту:
- «Добавь отправку заявок в Telegram»
- «Сделай тёмную тему»
- «Добавь фото биотуалетов»
- «Измени цены»
