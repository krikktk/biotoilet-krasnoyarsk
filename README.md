# Аренда биотуалетов в Красноярске

Готовый сайт на Python (Flask).

## Как запустить

```bash
pip install -r requirements.txt
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

## Что умеет

- Красивая адаптивная страница
- Блок преимуществ
- Карточки с ценами
- Форма заявки
- Сообщения об успешной отправке
- Заявки выводятся в консоль (легко подключить Telegram)
